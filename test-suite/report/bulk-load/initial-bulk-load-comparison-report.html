3. Observations

Both applications processed all 10 input transactions successfully.

Version A inserted 5 new records and identified 5 duplicates.

Version B inserted 4 new records and identified 6 duplicates.

The difference is consistent with the intentional deletion of TXN003 and addition of TXN006 in Version B before this bulk-load execution.

No records were rejected and no errors were reported by either application.

4. Conclusion

Both applications accepted the bulk-load request without errors. However, their existing data differed, resulting in different inserted and duplicate counts. This is an important finding for migration data validation.
